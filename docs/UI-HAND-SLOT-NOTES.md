# 手持出牌区 · 交互备注

## 待确认

- **键盘范围**：`←` / `→` / `Enter` 只在手持牌匾获得焦点时生效，不做全局监听，避免和棋盘 / 输入框 / 顶栏按钮抢键。Enter 对「简单动作」直接执行，对带参数动作打开确认详情。
- **滚轮方向**：向下 / 向右 = 下一张，向上 / 向左 = 上一张；手持区与 dock 都监听，累计 24px 记为一步。高分辨率触控板不会一次滚动跳过多张。
- **拖拽范围**：横向拖拽只在手持区生效（dock 上只监听滚轮）；鼠标必须横向，触摸 / 手写笔取主导轴。右 / 上 = 下一张，左 / 下 = 上一张，每 40px 一步，循环回绕。
- **held 索引重置**：快照刷新时优先按动作 id 保持当前手持项；该动作消失时保留原位置并夹到列表范围内，列表为空则清空。切换 presenter / 游戏 / 场景时重置到第一张。
- **长按与点击**：长按完成、或按下后移动超过 14px，都会吞掉随后的一次 click；释放过早不会执行动作，但普通 click 仍打开详情。参数化动作长按完成时打开详情（不直接派发），由用户再确认。
- **模型 / 放置模式**：手持区仍读取 `snapshot.actions`；此时 dock 的 fan 已被放置面板替换，因此可能暂时没有 `data-held` 的 fan 卡片可高亮。手持区仍可查看动作与参数，执行仍走原有 `runAction` 路径。
- **移动端**：视口 < 1200px 时隐藏手持区，dock 保持原有平板 / 手机底部抽屉行为。
- **冷却动作**：没有单独实现一套冷却计时；手持区沿用 dock 的 `runAction` / 动作快照语义，避免两套倒计时口径。
